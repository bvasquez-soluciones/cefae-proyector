## Cómo instalarlo

1. Descarga el instalador con el enlace de arriba.
2. Ábrelo y sigue los pasos. Se instala solo para tu usuario y crea el icono en el escritorio.
3. Si Windows muestra «Windows protegió su PC», pulsa **Más información** y luego **Ejecutar de todos modos**.

## Requisitos

- Windows 10 u 11 de 64 bits, 4 GB de memoria y 1 GB libre.
- Google Chrome o Microsoft Edge.
- Internet solo para las funciones en línea (YouTube, letras, IA).
